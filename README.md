# 🍽️ Plate2Plate

> A full-stack food redistribution platform that connects surplus food providers with receivers in real time — helping reduce food waste and improving food accessibility.

---

## 📌 Overview

Plate2Plate is a social impact platform designed to bridge the gap between food surplus and food scarcity. Restaurants, hotels, caterers, NGOs, and individuals can donate excess food, while verified receivers can locate and claim available food nearby in real time.

The platform aims to minimize food wastage, reduce hunger, and create a sustainable ecosystem through technology.

---

## ✨ Features

- 🍛 Donate surplus food in seconds
- 📍 Real-time location-based food listings
- 🔍 Search nearby available food donations
- 👥 Separate dashboards for donors and receivers
- 🔐 Secure user authentication
- 📦 Food availability and quantity tracking
- ⏰ Live status updates
- 📱 Responsive UI for desktop and mobile
- 🌍 Interactive map integration
- 📊 Donation history and activity logs

## 🚀 How It Works

1. A donor uploads details about surplus food.
2. The donation appears instantly on the platform.
3. Nearby verified receivers can view available food.
4. A receiver requests or claims the donation.
5. The donor confirms the request.
6. Food is successfully redistributed instead of wasted.
